# RunPilot

RunPilot 是作者为方便自己监控长时间的深度学习训练任务而写的开源技能，没有商业用途。它也能接管普通 Python 脚本：只需提供脚本路径，RunPilot 会读取任务并处理后续步骤。

可在本机使用，也可在已通过 SSH 登录的服务器上安装并运行；RunPilot 本身尚不负责建立 SSH 连接。

## 能做什么

- **接管 Python 任务**：给出脚本路径，识别运行环境和已有进程。
- **立即开启运行**：经授权和安全检查后，按原命令启动新任务。
- **按时巡查**：查看进程、日志进度、资源和完成状态；定时调用需要已有入口。
- **有事启奏**：记录并按配置通知完成、失败或异常；全部任务结束且 Agent 被唤醒后汇报主要结果。

## 安装

```sh
npx skills add https://github.com/OoooP0731/RunPilot --skill run-pilot
```

更新已安装的技能：`npx skills update run-pilot`（按提示选择原安装范围，并核对安装后的版本）。

## 快速开始：接受一个普通 Python 任务

下面是对话示例：在 Codex 中显式选择技能时，用 `$run-pilot` 代替示意称呼 `/RunPilot`。

```text
/RunPilot
接管 ./example.py 任务
```

## 谁在巡查？消耗 token 吗？

- **Agent 定时巡查**：每轮唤醒模型都会消耗 token，即使没有新情况；任务结束后可读取已有结果并汇报。
- **系统定时器（需另行配置）**：直接调用固定程序时，周期巡查本身不消耗模型 token；会保存状态，但不会自动唤醒 Agent。

**GPU 并行**：先评估逐卡显存、计算模式、其他资源、任务隔离和可能收益；由用户决定是否并行及上限，默认串行。

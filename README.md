# RunPilot

RunPilot 是作者为方便自己监控长时间的深度学习训练任务而写的开源技能，没有商业用途。它也能接管普通 Python 脚本：只需提供脚本路径，RunPilot 会读取任务并处理后续步骤。

可在本机使用，也可在已通过 SSH 登录的服务器上安装并运行；RunPilot 本身尚不负责建立 SSH 连接。

## 能做什么

- **接管 Python 任务**：读取脚本与运行环境，识别已有进程或准备新任务。
- **立即开启运行**：在授权和安全检查通过后启动任务；GPU 并行先评估，再由用户选择。
- **按时巡查**：检查进程、日志、资源和完成状态；周期调用需要用户已有的定时安排。
- **有事启奏**：记录完成、失败和监控异常；全部任务结束后报告主要结果。

## 安装

```sh
npx skills add https://github.com/OoooP0731/RunPilot --skill run-pilot
```

更新已安装的技能：`npx skills update run-pilot`（按提示选择原安装范围，并核对安装后的版本）。

## 快速开始：接受一个普通 Python 任务

下面是对话示例；在 Codex 中显式选择技能时，用 `$run-pilot` 代替示意称呼 `/RunPilot`：

```text
/RunPilot
接管 ./example.py 任务
```

## 持续监控、状态和通知

- **监控**：`example.py` 的进程、进度、资源与完成状态。已有系统定时器直接调用固定程序时，巡查本身不消耗模型 token；由 Codex/Agent 定时唤醒时，每轮消耗 token；都未配置时只有单次巡查。接管时会说明实际采用哪一种。
- **通知**：完成、失败或异常留下事件；配置后才会投递提醒。全部任务结束时，Agent 被唤醒后才会汇报项目已有的主要结果；固定程序不会自行唤醒 Agent。

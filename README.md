# RunPilot

RunPilot 是作者为方便自己监控长时间的深度学习训练任务而写的开源技能，没有商业用途。它也能接管普通 Python 脚本：只需提供脚本路径，RunPilot 会读取任务并处理后续步骤。

可在本机使用，也可在已通过 SSH 登录的服务器上安装并运行；RunPilot 本身尚不负责建立 SSH 连接。

## 能做什么

- **接管 Python 任务**：读取脚本与运行环境，识别已有进程或准备新任务。
- **立即开启运行**：在授权和安全检查通过后启动任务。
- **按时巡查**：检查进程、日志、资源和完成状态；周期调用需要宿主已有的定时安排。
- **有事启奏**：记录完成、失败和监控异常，并按已配置的方式通知。

## 安装

```sh
npx skills add https://github.com/OoooP0731/RunPilot --skill run-pilot
```

## 快速开始：接受一个普通 Python 任务

本仓库提供参考脚本 [`example.py`](example.py)。下面是对话示例；在 Codex 中显式选择技能时，用 `$run-pilot` 代替示意称呼 `/RunPilot`：

```text
/RunPilot
接管 ./example.py 任务
```

## 持续监控、状态和通知

- **监控**：`example.py` 的进程、日志进度、CPU/内存/磁盘、退出码与完成状态。没有已配置的定时调用时只能单次巡查。
- **通知**：任务完成、失败或监控异常会留下本地事件；配置文件通知或 macOS 桌面通知后才会投递提醒。

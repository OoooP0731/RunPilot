# 更新 RunPilot 技能

仅在用户要求检查/更新时执行，不在任务巡检中自动联网或自我替换。此模块更新**技能文件**，不升级 Python 项目、清空私有状态或重跑任务。

1. 先核对当前安装的 `SKILL.md` 中 `metadata.version`、安装路径和全局/项目范围，再看官方 GitHub Release 的最新版本；未发布的新 `main` 提交不冒充已发布版本。若 GitHub 无法访问，说明未知，不猜版本。
2. 告诉用户目标版本、安装范围、可能覆盖本地改动的风险。活动任务先保留状态与原调度入口；本流程不迁移未知状态 schema，不撤销正在运行的任务或待投递通知。
3. 经用户确认后，只更新 `run-pilot`，不要更新其他技能。根据原安装范围选择其一：

   ```sh
   npx skills update run-pilot -g
   npx skills update run-pilot -p
   ```

4. **核对实际文件**：重新读取安装目录的 `SKILL.md` 版本及内部引用，不以命令打印“成功”作为更新完成证据。原本已是目标版本时无需变动；若目标版本更高而安装文件仍旧，说明更新未完成，可在确认原安装范围后重新执行 README 中的单技能 `skills add` 安装命令并再核对，不盲目删除技能或私有状态。新会话重新加载技能；已有监控入口仍须按原状态核对。

`npx skills update` 是外部安装器，不属于固定 `check-once` 的零模型巡检；运行/对话中使用 Agent 仍消耗模型 token。
